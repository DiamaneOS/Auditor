DiamaneOS fork of [GrapheneOS Auditor](https://github.com/GrapheneOS/Auditor). Release builds use the
package ID `de.diamaneos.auditor`. The Java packages are unchanged.

The [release notes](https://github.com/DiamaneOS/Auditor/releases) list each release's changes, and the commit history has the earlier ones. Device specifics
and trusted keys are in `app/src/main/res/raw/diamaneos_trust.json`.

Upstream overview: https://attestation.app/about.
